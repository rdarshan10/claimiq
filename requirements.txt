# --- Notes ----------------------------------------------------------------
# LangChain is deliberately NOT a dependency. The pipeline needs control of
# every stage boundary for checkpoint/resume, and the audit trail must record
# the exact prompt and raw response sent to the provider — both work against
# a framework that abstracts the call. Groq is OpenAI-compatible, so the
# provider layer is ~40 lines in claimiq/providers/model.py. See ARCHITECTURE.md.
#
# No vector database. A claim pack is 20-80 pages and fits in context;
# chunk-retrieval actively hides cross-document contradictions, which are the
# highest-value findings. Cross-CLAIM search (fraud rings) is the case where a
# vector store earns its place — see the Phase 2 section of ARCHITECTURE.md.
